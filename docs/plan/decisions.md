- **D-016** 2026-09-29 · **NLI model: fp32** DeBERTa-v3-base-mnli-fever-anli (MIT; ONNX export Xenova @72a1ce83, sha256-pinned), run in a separate **akashi-nli** sidecar (1800m limit). It loads on demand (3.4 s on the server) and unloads after 15 idle minutes; `/claim` sends `/warm` first so loading overlaps the evidence fetch. **Evidence (51 labelled pairs, `packages/cite/calibration/nli_pairs.jsonl`):** fp32 100%; Xenova `model_int8` always answers "neutral" (broken); `model_quantized` 88% agreement; our MatMul-only per-channel int8 92%. Both 8-bit variants flip contradiction→entailment, so both fail the ≥95% gate. fp16 is slower on CPU with no memory gain. Loaded RSS 1.21 GiB; 8 pairs 0.35 s warm · measured.
- **D-017** 2026-09-29 · `/claim` evidence chain: provided text → **Europe PMC** abstract (free, no key; covers LeCun/Nature, Lancet, NEJM) → OpenAlex abstract → DataCite abstract (arXiv). A deciding sentence must share a content word with the claim (guards an unrelated "MRI and EEG tests were normal" read as contradicting "MMR causes autism"). Verdicts: supported / contradicted / insufficient_evidence / unverifiable · live gate.

- **D-023** 2026-09-30 · **Stocks: Massive's all-market grouped daily is the ticker check, not the SEC list.** The spec's SEC-tickers validation would reject every ETF (QQQ, VOO are not SEC company tickers). Out of Twelve Data credits → the Massive close, labelled, envelope partial. SEC names are used only for did-you-mean. No worker job (D-018): everything is on demand.
