# Akashi 証

> Is this real, and is it current?

Verification services for AI agents on **Pocket Network's Agentic Portal**:

| Service ID | What it checks |
|---|---|
| `citation-verify` | scholarly, legal and web citations → verified / mismatch / not_found / retracted / ambiguous / unverifiable |
| `code-reality-check` | packages, versions and symbols exist (with real signatures), typo-squats, placeholders |
| `live-facts` | time, holidays, FX, weather, news, jobs, facts — each with source, `as_of` and cross-source agreement |

Built for the Pocket Network Agentic Services Hackathon (deadline 2026-10-12).
