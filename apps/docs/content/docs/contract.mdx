title: The response contract
eyebrow: Start · contract
description: Every call returns one JSON object, errors included. A success says which sources were consulted and whether any failed; an outage becomes a partial answer, never a server error.
---

## The envelope

| Field | Meaning |
|---|---|
| `service`, `operation`, `version` | which service and endpoint answered, and the release |
| `status` | `complete`, or `partial` when a source did not answer in time (it is named in `unavailable`) |
| `as_of` | when the answer was assembled, UTC |
| `deadline_ms`, `elapsed_ms` | the service's hard stop and the time this answer took |
| `unavailable` | the sources that failed, by name |
| `summary` | how many results carry each verdict, e.g. `{"verified": 3, "not_found": 1}` |
| `results` | one typed result per input, each with its own verdict or provenance |
| `sources` | every upstream consulted: `status`, licence, attribution and, when known, latency and cache state |
| `notes` | anything the answer should be read with |

Hard stops: Citation Verifier 8.5 s, Code Reality Check 7 s, Live Facts 4 s. Whatever has not arrived by then is
listed in `unavailable`, and the items it affected say so (`unverifiable` or `unknown`, with `retryable: true`).

## Source status

Each entry in `sources` carries one of: `ok`, `not_found`, `unavailable`, `rate_limited`, `skipped_budget`
(not asked, to stay inside the deadline) or `not_applicable` (the source does not cover this input, such as the
US weather service for Berlin).

## Errors

An error is `{"error": {"code", "message", "retryable", "details"}}`.

| HTTP | `code` | When |
|---|---|---|
| 400 | `invalid_json` | the body is not JSON |
| 404 | `not_found` | no such path |
| 405 | `method_not_allowed` | the path exists, the method does not |
| 413 | `payload_too_large` | the body is over 64 KiB |
| 422 | `invalid_input` | valid JSON that fails validation; `details` names each field |
| 422 | `unsupported` | a well-formed request this deployment does not serve (stock quotes switched off) |
| 500 | `internal` | a bug on our side; `retryable: true` |

An upstream outage is never an error: it is a `partial` success.

## Paths

Paths are prefix-free (`/v1/...`), exactly as Pocket gateways forward them. Inputs travel only in the JSON body.
