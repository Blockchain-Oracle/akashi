description: Every Akashi endpoint, generated from the OpenAPI each service publishes, with a playground that calls the API directly.
---

Each page shows the request body, every response field and a code sample, and has a **playground**: fill in the
body and press **Send**. Playground requests go straight to the Akashi API (free, unmetered); paid calls go through
the Pocket portal as described in [Call Akashi](/docs/calling).

Paths are prefix-free (`/v1/...`), exactly as Pocket gateways forward them.
