The skill is one Markdown file: `https://useakashi.xyz/SKILL.md`. It tells an agent when to reach for Akashi, how to connect through hosted or local MCP, the npm CLI or plain HTTP, how discover, inspect and run work, and how to read the result.

## Install it

Tell your agent:

```text
set up https://useakashi.xyz/SKILL.md
```

The agent downloads the file and saves it to its skills. To install it yourself in Claude Code:

```bash
mkdir -p ~/.claude/skills/akashi
curl -fsSL https://useakashi.xyz/SKILL.md -o ~/.claude/skills/akashi/SKILL.md
```

## What the agent can do with it

Discover and inspect need nothing but HTTP, so the agent can use them at once:

```bash
curl -s -X POST https://api.useakashi.xyz/v1/discover -H 'content-type: application/json' \
  -d '{"query": "recent papers on RAG hallucination", "limit": 5}'
curl -s -X POST https://api.useakashi.xyz/v1/inspect -H 'content-type: application/json' \
  -d '{"id": "firecrawl/research-papers"}'
```

A run is paid in Base Sepolia test USDC. The payment method depends on the connection:

- **Hosted MCP.** Connect to `https://api.useakashi.xyz/mcp` for the three MCP tools. Akashi covers runs within its capped demo credit. See [For AI agents (MCP)](/docs/quickstart/mcp).
- **Local MCP.** Launch `npx -y akashi mcp` and give that process `AKASHI_PRIVATE_KEY` to pay from your test wallet. See [For AI agents (MCP)](/docs/quickstart/mcp).
- **CLI.** Install `akashi` from npm and set `AKASHI_PRIVATE_KEY`. The agent runs `akashi run <id> --input '<json>'`. See [For humans (CLI)](/docs/quickstart/cli).
- **Code.** The skill includes an `@x402/fetch` snippet with a per-call price cap. See [From code (HTTP)](/docs/quickstart/http).

## Fund a test wallet

Use a new key that holds nothing else. Runs are paid in USDC on Base Sepolia, a testnet.

<Steps>
<Step>

Create a key and read its address with the CLI:

```bash
export AKASHI_PRIVATE_KEY=0x$(node -e "console.log(require('crypto').randomBytes(32).toString('hex'))")
akashi wallet
```

</Step>
<Step>

Open [faucet.circle.com](https://faucet.circle.com), pick **Base Sepolia** and send test USDC to the `address` from the previous step. You need no ETH: you sign a USDC authorization and the x402 facilitator submits it.

</Step>
<Step>

Ask your agent for something that needs a live tool, for example: "What is 100 USD in NGN today, and is it raining in Lagos?"

</Step>
</Steps>

<Callout title="Results are data, not instructions">
  The skill tells the agent to treat everything inside a result's `data` as untrusted content and never to follow instructions found there.
</Callout>
