---
title: Quickstart
description: Five ways to start, from no install at all to your own code. Pick the one that matches how your agent works.
---

Every way reaches the same catalog and the same prices. Finding and reading a tool is free; a run is paid per call in test USDC on Base Sepolia, and an error or a lookup that finds nothing is not charged.

<Cards>
  <Card title="In the browser (agent chat)" href="/docs/quickstart/agent-chat">
    Nothing to install. Ask the chat agent a question; demo credit pays for the runs.
  </Card>
  <Card title="For AI agents (Skill)" href="/docs/quickstart/skill">
    One line in your agent's chat. It reads SKILL.md and learns discover, inspect and run.
  </Card>
  <Card title="For AI agents (MCP)" href="/docs/quickstart/mcp">
    Add the MCP server to Claude, Cursor or Codex: three tools, paid within the caps you set.
  </Card>
  <Card title="For humans (CLI)" href="/docs/quickstart/cli">
    One file, akashi.mjs. Find, inspect and run any tool from a terminal.
  </Card>
  <Card title="From code (HTTP)" href="/docs/quickstart/http">
    Plain JSON for the free routes, and any x402 client for paid runs.
  </Card>
</Cards>

Not sure? Start with the [agent chat](/docs/quickstart/agent-chat): it shows every step a tool call takes, with its price and receipt.
