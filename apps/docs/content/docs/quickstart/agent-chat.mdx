---
title: In the browser (agent chat)
description: Try Akashi without installing anything. A chat agent finds, inspects and runs tools for you, paid with demo credit or your own wallet.
---

Open [`https://useakashi.xyz/agent`](https://useakashi.xyz/agent) and ask a question that needs live data, for example "Is it raining in Lagos right now, and what is 100 USD in NGN today?".

The agent works the same way any Akashi client does. It searches the catalog, reads the contract of the tool it picked, then runs it. Each step shows in the conversation.

## Two ways to pay

| Mode | Who pays | What you need |
| --- | --- | --- |
| Demo credit | Akashi's demo wallet, within a small daily limit per visitor | Nothing |
| Your wallet | You: your browser wallet signs each x402 payment, at most $0.01 per call | A wallet on Base Sepolia with test USDC from [faucet.circle.com](https://faucet.circle.com) |

Either way, the runs are real: the same gateway, the same prices, the same settlement on Base Sepolia. A failed run is not charged in either mode.

## When to move on

The chat is a demo. To give your own agent the same tools, use the [Skill](/docs/quickstart/skill), the [MCP server](/docs/quickstart/mcp) or the [CLI](/docs/quickstart/cli).
