title: For judges
description: Test Akashi end to end in about ten minutes. The free routes with curl, the 402, a paid run with the CLI, a run that is not charged, the agent chat, and the on-chain records.
---

Everything below runs against the public gateway. Steps 1 and 2 need only `curl` (and `jq` to read the output). Step 3 needs Node.js 20 or later and test USDC.

```bash
API=https://api.useakashi.xyz
```

## 1. The free routes

```bash
curl -s $API/v1/version
curl -s $API/v1/health
curl -s $API/v1/catalog | jq '{hash, providers: (.providers | length), tools: (.endpoints | length)}'
```

`/v1/version` names the service (`tool-router`), the catalog hash, the `payTo` address and whether runs are relayed (`"relay": "pocket"`) or not (`"relay": "direct"`).

Find a tool and read its contract:

```bash
curl -s -X POST $API/v1/discover -H 'content-type: application/json' \
  -d '{"query": "latest release of a github repo", "limit": 3}' \
  | jq '.candidates[] | {id, price: .price.usd, health: .health.status}'

curl -s -X POST $API/v1/inspect -H 'content-type: application/json' \
  -d '{"id": "github/latest-release"}' | jq '{id, price, example, fields: (.input.properties | keys)}'
```

## 2. The 402

Call a tool without paying:

```bash
curl -si -X POST $API/v1/run/github/latest-release \
  -H 'content-type: application/json' -d '{"repo": "astral-sh/uv"}' | head -n 1
```

The status is `402`. Decode the price from the header:

```bash
curl -s -D - -o /dev/null -X POST $API/v1/run/github/latest-release \
  -H 'content-type: application/json' -d '{"repo": "astral-sh/uv"}' \
  | grep -i '^payment-required:' | cut -d' ' -f2 | tr -d '\r' | base64 -d | jq '.accepts[0]'
```

Expect `"scheme": "exact"`, `"network": "eip155:84532"`, `"amount": "1000"` ($0.001), the USDC address `0x036CbD53842c5426634e7929541eC2318f3dCF7e` and `"payTo": "0x8164dabAfc824322221654ED421715FdaA66948D"`.

## 3. A paid run with the CLI

```bash
curl -fsSLO https://useakashi.xyz/akashi.mjs
export AKASHI_API_URL=$API
export AKASHI_PRIVATE_KEY=0x$(node -e "console.log(require('crypto').randomBytes(32).toString('hex'))")
node akashi.mjs wallet
```

Send test USDC on Base Sepolia to the printed `address` from [faucet.circle.com](https://faucet.circle.com). No ETH is needed. Then:

```bash
node akashi.mjs run github/latest-release --input '{"repo": "astral-sh/uv"}'
```

Check the output:

- `status` is `200` and `body.data` holds the release.
- `receipt.paid` is `true` and `receipt.transaction` is the settlement. Open `https://sepolia.basescan.org/tx/<transaction>`: a USDC transfer of 0.001 to `0x8164…948D`.
- `receipt.via` is `pocket` (relayed through Pocket Network) or `direct` (the gateway's fallback).

## 4. Runs that are not charged

A lookup that finds nothing:

```bash
node akashi.mjs run wikipedia/summary --input '{"title": "Qzxv Nonexistent Article Akashi"}'
```

`status` is `404`, `body.found` is `false` and `receipt.paid` is `false`. An input with a typo:

```bash
node akashi.mjs run wikipedia/summary --input '{"titel": "Alan Turing"}'
```

`status` is `422` with `"code": "invalid_input"`, and `receipt.paid` is `false`. The typo is caught by the free input check before any payment is asked for, so nothing is signed. The lookup that found nothing was signed, and the gateway never settled it.

## 5. The agent chat

Open [`https://useakashi.xyz/agent`](https://useakashi.xyz/agent) and ask "Find three recent papers on detecting hallucinations in RAG systems". Use the demo credit, or connect a Base Sepolia wallet to pay yourself. Each tool call shows in the conversation.

## 7. The Service Audit

Pocket's acceptance check runs rules A1 to A9 against the live network: registration, the card, the supplier, the endpoint's TLS, a settled claim, the card's probes and the price. [Run it for `tool-router`](https://mcp.pocketmcp.network/audit?network=beta&ids=tool-router&operator=pokt1qnrjr3susgpyh4a4rx8f0x0wd6pqdtptr50ayg), or:

```bash
curl -s 'https://mcp.pocketmcp.network/api/audit?network=beta&ids=tool-router&operator=pokt1qnrjr3susgpyh4a4rx8f0x0wd6pqdtptr50ayg' \
  | jq '.services[0] | {verdict, rules}'
```

On 2026-10-07 it returned `PASS` on all nine rules with no findings.

For how the pieces fit, see [How it runs on Pocket](/docs/pocket).
