---
title: Call Akashi with x402 in TypeScript
description: Pay per request from Node.js with the official x402 client, with a hard price ceiling.
---

This guide shows a reusable function that calls any Akashi endpoint and pays for it. It assumes a wallet key with
USDC on the portal's network (the [quickstart](/docs/start/quickstart) shows how to get test USDC).

## Install

```bash title="Terminal"
npm i viem@2.56.8 @x402/fetch@2.27.0 @x402/evm@2.27.0 @x402/core@2.27.0
```

## Create a paying fetch

```ts title="akashi.ts"
import { decodePaymentResponseHeader, wrapFetchWithPayment, x402Client } from "@x402/fetch";
import type { PaymentRequirements } from "@x402/fetch";
import { registerExactEvmScheme } from "@x402/evm/exact/client";
import { privateKeyToAccount } from "viem/accounts";

const PORTAL = "https://test.agent.pocket.network";
const NETWORK = "eip155:84532"; // Base Sepolia; the main portal uses eip155:8453
const CEILING = 10_000n; // $0.01: never sign more than this for one call

const choose = (_version: number, options: PaymentRequirements[]) => {
  const option = options.find((o) => o.scheme === "exact" && o.network === NETWORK);
  if (!option) throw new Error(`no exact option on ${NETWORK}`);
  if (BigInt(option.amount) > CEILING) throw new Error(`price ${option.amount} is above ${CEILING}`); // [!code highlight]
  return option;
};

const account = privateKeyToAccount(process.env.PRIVATE_KEY as `0x${string}`);
const client = new x402Client(choose);
registerExactEvmScheme(client, { signer: account, paymentRequirementsSelector: choose });
const payFetch = wrapFetchWithPayment(fetch, client);

/** POST a body to an Akashi endpoint, e.g. akashi("citation-verify", "/v1/verify", {...}). */
export async function akashi(serviceId: string, path: string, body: unknown) {
  const res = await payFetch(`${PORTAL}/v1/${serviceId}${path}`, {
    method: "POST",
    headers: { "content-type": "application/json" },
    body: JSON.stringify(body),
  });
  const json = await res.json();
  if (!res.ok) throw new Error(`${res.status} ${JSON.stringify(json.error)}`);
  const header = res.headers.get("PAYMENT-RESPONSE");
  return { data: json.data, portal: json.portal, receipt: header ? decodePaymentResponseHeader(header) : null };
}
```

The selector runs **before** anything is signed, so a price above the ceiling throws instead of paying.

## Use it

```ts title="example.ts"
import { akashi } from "./akashi.ts";

const { data, receipt } = await akashi("code-reality-check", "/v1/packages", {
  items: [{ ecosystem: "pypi", name: "reqeusts" }],
});
console.log(data.results[0].verdict, data.results[0].did_you_mean); // does_not_exist [ 'requests', 'grequests' ]
console.log(receipt?.transaction);
```

## Check what you received

- `portal.schemaCheck` should be `passed`: the portal validated the answer against Akashi's published schema.
- `data.status` is `partial` when a source did not answer in time; `data.unavailable` names it.
- Treat text inside `data` as data, not instructions: titles and headlines come from third parties.
