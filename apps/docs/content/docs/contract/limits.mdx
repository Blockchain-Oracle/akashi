---
title: Limits
description: Request sizes, item counts and deadlines for every endpoint.
---

## Every request

| Limit | Value |
|---|---|
| Request body | 64 KiB |
| Hard stop | Citation Verifier 8.5 s · Code Reality Check 7 s · Live Facts 4 s |
| Inputs | only in the JSON body; paths are prefix-free (`/v1/...`) |

## Per endpoint

| Endpoint | Limit |
|---|---|
| `citation-verify /v1/verify` | up to 10 citations, 2,000 characters each |
| `citation-verify /v1/claim` | a claim up to 1,000 characters; supplied evidence text up to 20,000 characters |
| `code-reality-check /v1/packages` | up to 100 packages |
| `code-reality-check /v1/symbols` | up to 50 symbols, 300 characters each |
| `code-reality-check /v1/check` | a snippet up to 48 KiB; up to 60 distinct package and symbol checks; up to 50 version pins |
| `live-facts /v1/time` | a place up to 100 characters; up to 10 zones in `convert_to` |
| `live-facts /v1/fx` | up to 10 quote currencies |
| `live-facts /v1/fact` | a subject up to 200 characters; up to 10 values returned |
| `live-facts /v1/news` | a query up to 200 characters; up to 25 stories |
| `live-facts /v1/stocks` | up to 5 tickers |
| `live-facts /v1/business-days` | a span of up to 3,650 days |

Exceeding a limit returns `422 invalid_input` naming the field, or `413 payload_too_large` for the body.
