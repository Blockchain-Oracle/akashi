---
title: Words, explained
description: The terms used in these docs, in plain English.
---

| Word | Meaning |
|---|---|
| **AI agent** | A program that uses an AI model to do tasks on its own: answer questions, write code, book things. |
| **Hallucination** | When an AI states something false as if it were true, such as a court case that does not exist. |
| **Citation** | A reference to a source: a court case, a research paper or a web page. |
| **Package** | A ready-made piece of code that programmers install instead of writing it themselves. |
| **Verdict** | Akashi's one-word answer, such as `verified`, `not_found` or `retracted`. Always shown with a symbol and a colour. |
| **Provenance** | Where an answer came from and how old it is. |
| **Retracted** | Withdrawn by its publisher, usually because it was wrong. |
| **Pocket Network** | A network of independent computers that serve services to apps and agents, paid per use. |
| **Agentic Portal** | Pocket's front door for AI agents: it lists services, takes payment and passes the question on. |
| **Service ID** | The permanent name of a service on Pocket, e.g. `citation-verify`. |
| **Relay** | One question passed through Pocket Network to a service and its answer back. |
| **Supplier** | Whoever runs a service on Pocket and gets paid for answering relays. For Akashi, that is Akashi. |
| **USDC** | A digital dollar. Agents pay Akashi half a cent (0.005 USDC) per check. |
