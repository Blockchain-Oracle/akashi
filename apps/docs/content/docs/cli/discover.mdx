---
title: discover
description: Rank the catalog for a job described in plain words. Free.
---

```bash
node akashi.mjs discover "<what you need>" [--limit N]
```

All words that are not flags form the query, so quotes are optional: `discover weather in Lagos` and `discover "weather in Lagos"` are the same.

| Flag | Default | Meaning |
| --- | --- | --- |
| `--limit N` | `5` | How many candidates to return (the API accepts 1 to 25) |

It calls [`POST /v1/discover`](/docs/api/discover) with `{query, limit}` and prints the response.

```bash
node akashi.mjs discover "weather in Lagos" --limit 2
```
