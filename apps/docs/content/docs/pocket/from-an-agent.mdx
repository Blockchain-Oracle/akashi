---
title: Calling Akashi from an agent
description: Through Pocket's MCP server, or the portal's HTTP route.
---

<McpFlow />

**In Claude, Cursor or any MCP client**, add Pocket's MCP server with a wallet and a spending cap:

```json title="MCP configuration"
{
  "mcpServers": {
    "pocket-network": {
      "command": "npx",
      "args": ["-y", "@pocket-network/agentic-portal-mcp"],
      "env": { "POCKET_PRIVATE_KEY": "0x…", "POCKET_MAX_PER_CALL_ATOMIC": "10000" }
    }
  }
}
```

Then ask: *"Verify this citation with citation-verify: Varghese v. China Southern Airlines Co., 925 F.3d 1339."*

**Over HTTP**, every Akashi endpoint is the portal, the service ID, then the path:

```text title="Portal routes"
POST https://agent.pocket.network/v1/citation-verify/v1/verify
POST https://agent.pocket.network/v1/code-reality-check/v1/check
POST https://agent.pocket.network/v1/live-facts/v1/fx
```

The request bodies and answer types are in [Services](/docs/services/cite) and the [API reference](/docs/reference).
