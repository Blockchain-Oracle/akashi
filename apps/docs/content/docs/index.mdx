Akashi is an OpenRouter for agent tools. One Pocket Network service, `tool-router` (Akashi Tool Router), sits in front of 80 tools from 33 providers: web search and page reading, cited answers, research papers, news, weather (16-day forecasts and history since 1940), maps and geocoding, crypto prices and FX, GitHub and packages, time zones and holidays, dictionaries and more.

Your agent finds a tool, reads its contract and runs it. It pays per run in test USDC on Base Sepolia, with the x402 protocol. It needs no Akashi account and no provider API keys: a wallet with test USDC is enough.

## How it works

Three verbs. The first two are free.

<Steps>
<Step>

**Discover** (free). Describe the job in plain words. Akashi ranks the catalog and returns candidates, each with its id, price, health (status, p50 and p95 run time) and hints on what to call next.

</Step>
<Step>

**Inspect** (free). Read one tool's contract: what it does and what it will not do, its input JSON Schema, its output schema, its price and a working example.

</Step>
<Step>

**Run** (paid per call). Send the tool's input as the JSON body. The first answer is `402 Payment Required` with the exact price. An x402 client signs the payment and retries. A `200` means the run succeeded and the payment settled. A failed run is never charged.

</Step>
</Steps>

```bash title="Discover, then inspect (no wallet needed)"
curl -s -X POST https://api.useakashi.xyz/v1/discover \
  -H 'content-type: application/json' \
  -d '{"query": "weather in Lagos", "limit": 3}'

curl -s -X POST https://api.useakashi.xyz/v1/inspect \
  -H 'content-type: application/json' \
  -d '{"id": "openweather/current"}'
```

```bash title="Run (pays $0.005 from AKASHI_PRIVATE_KEY)"
node akashi.mjs run openweather/current --input '{"city":"Lagos"}'
```

## What happens to a run

The public gateway at `https://api.useakashi.xyz` checks the payment. It then sends the run through Pocket Network as a real relay, signed with Akashi's staked application. Akashi's supplier (a RelayMiner) passes it to the `tool-router` backend, which calls the upstream tool. The gateway settles the payment only when the run succeeds. See [How it runs on Pocket](/docs/pocket).

## The tools

Each tool has an id of the form `provider/endpoint`, such as `firecrawl/search` or `openweather/current`. Prices are $0.001, $0.005 or $0.01 per call. Browse them in [Tools](/docs/tools), or ask `discover`.
