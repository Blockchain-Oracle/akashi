Akashi (証, *proof*) checks the three things agents most often get wrong with confidence: whether a citation is
real and says what it is cited for, whether the packages and symbols in a snippet exist, and what is true right
now. Each check is a separate service with its own capability ID on Pocket Network.

## The response contract

Every response is one JSON object, errors included. A success carries:

| Field | Meaning |
|---|---|
| `status` | `complete`, or `partial` when an upstream source did not answer (named in `unavailable`) |
| `as_of` | when the answer was assembled (UTC) |
| `deadline_ms`, `elapsed_ms` | the hard stop for this service and the time taken |
| `summary` | counts per verdict |
| `results` | one typed result per input, each with its own provenance |
| `sources` | every upstream consulted, with its status, licence and attribution |

An error is `{"error": {"code", "message", "retryable", "details"}}` with a 4xx status. An upstream outage never
becomes a 5xx: it becomes a partial result.

Paths are prefix-free (`/v1/...`), exactly as Pocket gateways send them.
