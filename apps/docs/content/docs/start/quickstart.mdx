title: Quickstart
description: Check a citation through Pocket Network's test portal and pay for it with test USDC. About three minutes.
---

In this tutorial you will ask Akashi whether a legal citation is real, pay the $0.005 fee in **test** USDC, and
find your payment on a block explorer. You will write one small TypeScript file.

You need:

- Node.js 22.18 or later (it runs `.ts` files directly)
- A terminal and a browser

<Callout type="warn" title="Listing status">
Akashi is registered on Pocket Network and is waiting to be listed on the test portal. Until it is, the portal
answers `404` for `citation-verify`. Every step below is the same for any listed service: to rehearse the payment
flow now, use `SERVICE_ID=literature-search`, `SUB_PATH=/v1/literature` and `BODY='{"query":"aspirin","limit":1}'`.
</Callout>

<Steps>
<Step>

### Create a project

```bash title="Terminal"
mkdir akashi-quickstart && cd akashi-quickstart
npm init -y && npm pkg set type=module
npm i viem@2.56.8 @x402/fetch@2.27.0 @x402/evm@2.27.0 @x402/core@2.27.0
```

`@x402/fetch` pays for HTTP requests; `viem` holds the wallet key that signs the payment.

</Step>
<Step>

### Create a test wallet

```ts title="key.ts"
import { generatePrivateKey, privateKeyToAccount } from "viem/accounts";

const key = generatePrivateKey();
console.log(`PRIVATE_KEY=${key}`);
console.log(`# address: ${privateKeyToAccount(key).address}`);
```

```bash title="Terminal"
node key.ts > .env && cat .env
```

You should see a `PRIVATE_KEY=0x…` line and the wallet's address.

<Callout type="error">This key is for test tokens only. Never put a key that holds real funds in a file.</Callout>

</Step>
<Step>

### Get test USDC

Open [faucet.circle.com](https://faucet.circle.com), choose **Base Sepolia**, paste the address and request USDC.
One call costs 0.005 USDC, so a single faucet request covers many calls. You do not need ETH: the payment is a
signed authorization, and the facilitator pays the gas.

</Step>
<Step>

### See the price (free)

Ask for the resource without paying. The portal answers `402 Payment Required` with its terms:

```bash title="Terminal"
curl -s -X POST https://test.agent.pocket.network/v1/citation-verify/v1/verify \
  -H 'content-type: application/json' \
  -d '{"citations":["Varghese v. China Southern Airlines Co., 925 F.3d 1339 (11th Cir. 2019)"]}'
```

```json title="402 terms from the test portal (real, trimmed to accepts)"
{
  "x402Version": 2,
  "accepts": [
    {
      "scheme": "exact",
      "network": "eip155:84532",
      "amount": "5000",
      "asset": "0x036CbD53842c5426634e7929541eC2318f3dCF7e",
      "payTo": "0xF732ea490c5766071785a2310523f7fA2CEbB829",
      "maxTimeoutSeconds": 60,
      "extra": { "name": "USDC", "version": "2" }
    }
  ]
}
```

`network` is Base Sepolia, `asset` is its USDC contract, and `amount` is in USDC's smallest unit (6 decimals):
5000 = $0.005.

</Step>
<Step>

### Pay and call

```ts title="verify.ts"
import { decodePaymentResponseHeader, wrapFetchWithPayment, x402Client } from "@x402/fetch";
import type { PaymentRequirements } from "@x402/fetch";
import { registerExactEvmScheme } from "@x402/evm/exact/client";
import { privateKeyToAccount } from "viem/accounts";

const URL = "https://test.agent.pocket.network/v1/citation-verify/v1/verify";
const NETWORK = "eip155:84532"; // Base Sepolia
const CEILING = 10_000n; // refuse to sign anything above $0.01

// Pick the exact-price option on Base Sepolia, and stop before signing if it costs more than the ceiling.
const choose = (_version: number, options: PaymentRequirements[]) => {
  const option = options.find((o) => o.scheme === "exact" && o.network === NETWORK);
  if (!option) throw new Error(`no exact option on ${NETWORK}`);
  if (BigInt(option.amount) > CEILING) throw new Error(`price ${option.amount} is above ${CEILING}`);
  return option;
};

const account = privateKeyToAccount(process.env.PRIVATE_KEY as `0x${string}`);
const client = new x402Client(choose);
registerExactEvmScheme(client, { signer: account, paymentRequirementsSelector: choose });
const payFetch = wrapFetchWithPayment(fetch, client);

const res = await payFetch(URL, {
  method: "POST",
  headers: { "content-type": "application/json" },
  body: JSON.stringify({ citations: ["Varghese v. China Southern Airlines Co., 925 F.3d 1339 (11th Cir. 2019)"] }),
});
const body = await res.json();
const receipt = res.headers.get("PAYMENT-RESPONSE");

console.log("receipt:", receipt ? decodePaymentResponseHeader(receipt) : "(none: do not assume it was paid)");
console.log("portal:", body.portal);
console.log("verdict:", body.data.results[0].verdict, body.data.results[0].reasons);
```

```bash title="Terminal"
node --env-file=.env verify.ts
```

`payFetch` sends the request, receives the 402, signs a USDC authorization for exactly 5000 units and sends the
request again with the signature. The portal forwards it through Pocket Network to Akashi and returns
`{ portal, data }`: `portal` describes the delivery, and `data` is Akashi's answer:

```json title="data.results[0] (real response from Akashi)"
{
  "kind": "citation",
  "index": 0,
  "input_kind": "legal",
  "verdict": "not_found",
  "confidence": 0.95,
  "legal": {
    "reporter": "F.3d",
    "volume": "925",
    "page": "1339",
    "link": "https://www.courtlistener.com/c/F.3d/925/1339/",
    "covered_through": 2019
  },
  "reasons": [
    "page_inside_other_case",
    "page 1339 falls inside J.D. v. Azar (925 F.3d 1291-1349); no case starts there"
  ],
  "retryable": false
}
```

The citation is not real: page 1339 of that volume is in the middle of another case.

</Step>
<Step>

### Find your payment

`receipt.transaction` is the transfer's hash. Open `https://sepolia.basescan.org/tx/<transaction>` to see 0.005 USDC
move from your address to the portal.

</Step>
</Steps>

## What you did

You bought one verification with no account and no API key: the price came from the 402, your wallet signed exactly
that amount, and the answer carries the evidence behind the verdict.
