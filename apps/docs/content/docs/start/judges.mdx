## 典 Citation Verifier

`POST /v1/verify` with `{"citations": [...]}`:

| Citation | Verdict | What it shows |
|---|---|---|
| `Varghese v. China Southern Airlines Co., 925 F.3d 1339 (11th Cir. 2019)` | `not_found` | the invented case from *Mata v. Avianca*: page 1339 falls inside *J.D. v. Azar* (1291–1349) |
| `10.1016/S0140-6736(97)11096-0` | `retracted` | Wakefield's 1998 MMR paper, retracted on 2010-02-06 |
| `arXiv:1706.03762` | `verified` | *Attention Is All You Need*, matched to the 2017 arXiv record |

## 符 Code Reality Check

`POST /v1/packages` with `{"items": [{"ecosystem": "...", "name": "..."}]}`, and `POST /v1/check` for a snippet:

| Input | Verdict | What it shows |
|---|---|---|
| npm `react-codeshift` | `placeholder` | a name registered to hold nothing; the evidence quotes its description |
| npm `left-padx` | `does_not_exist` | suggests `left-pad`, one edit away |
| PyPI `reqeusts` | `does_not_exist` | suggests `requests` |
| JavaScript `axios.fetchJson("/api")` | `nonexistent_symbol` | axios has no `fetchJson`, checked against its published type definitions |

## What to look for

- The verdict is a fixed word, and every verdict carries its reason and source.
- Nothing is invented to fill a gap: a source that did not answer is named in `unavailable`.
- `retryable` says whether asking again could change the answer.
