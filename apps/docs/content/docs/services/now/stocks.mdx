---
title: What is the stock price?
description: POST /v1/stocks quotes up to five US tickers, checks each ticker first, and cross-checks the last close across two feeds. Demo-grade.
---

<Callout type="warn" title="Demo-grade">
  Quotes come from free market-data plans that forbid redistribution. Every quote is labelled
  `demo-only; not for redistribution`.
</Callout>

A ticker is first checked against every US ticker that traded in the last session. A typo is `not_found` with
suggestions instead of some other instrument's price.

## Request

<TypeTable
  type={{
    symbols: { type: "string[]", description: "1 to 5 US tickers, e.g. AAPL, SPY, BRK.B (BRK-B and BRK/B also work).", required: true },
  }}
/>

## Response: `results[i]`

<TypeTable
  type={{
    status: { type: "string", description: "ok, not_found or unavailable." },
    price: { type: "number | null", description: "The latest price; the official close when price_is_close is true." },
    session_date: { type: "string | null", description: "The trading day the price belongs to." },
    "previous_close, change, change_pct": { type: "number | null", description: "Against the previous session." },
    close_check: { type: "CloseCheck | null", description: "The same session's close from Twelve Data and Massive, and their agreement." },
    market: { type: "MarketClock", description: "The NYSE clock: state (open, pre_market, after_hours, closed), next_open_at, early_close." },
    suggestions: { type: "{ symbol, name }[]", description: "Up to three real tickers, when not_found." },
  }}
/>

## Example

```json title="{ symbols: [AAPL, APPL] } · results (trimmed)"
[
  {
    "symbol": "AAPL",
    "status": "ok",
    "name": "Apple Inc.",
    "price": 329.4,
    "price_is_close": true,
    "session_date": "2026-09-29",
    "close_check": { "session_date": "2026-09-29", "twelvedata": 329.4, "massive": 329.4, "agreement": "agree", "spread_pct": 0.0 },
    "market": { "calendar": "NYSE", "state": "pre_market", "next_open_at": "2026-09-30T09:30:00-04:00" }
  },
  {
    "symbol": "APPL",
    "status": "not_found",
    "suggestions": [
      { "symbol": "AAPL", "name": "Apple Inc." },
      { "symbol": "AMAT", "name": "APPLIED MATERIALS INC /DE" },
      { "symbol": "APP", "name": "AppLovin Corp" }
    ],
    "notes": ["APPL did not trade on a US exchange on 2026-09-29: a typo, a delisted company or not a US listing"]
  }
]
```

## Reading it

- `close_check` compares the one number both feeds publish independently; within 0.1 % is `agree`.
- The NYSE clock knows closures and early closes (1 p.m. the day after Thanksgiving and on Christmas Eve).
- A quote from before the last session is `stale`, with a note on when it last traded.
