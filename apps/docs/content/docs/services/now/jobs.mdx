---
title: Who is hiring?
description: POST /v1/jobs searches postings from 89 public company job boards (Greenhouse, Lever, Ashby), refreshed every 6 hours.
---

Postings come from Akashi's own index of public job boards, so a request never waits on the boards themselves.

## Request

All fields are optional; with none, you get the newest postings.

<TypeTable
  type={{
    query: { type: "string", description: "Words that must all appear in the title or team." },
    companies: { type: "string[]", description: "Up to 20 company names." },
    location: { type: "string", description: "Words in the location, e.g. Berlin." },
    remote: { type: "boolean", description: "true: remote only; false: not marked remote." },
    salary_min: { type: "integer", description: "Only postings stating a salary at or above this." },
    currency: { type: "string", description: "ISO 4217 code the salary must be in." },
    posted_within_days: { type: "integer", description: "1 to 90.", default: "90" },
    limit: { type: "integer", description: "1 to 50.", default: "10" },
  }}
/>

## Response: `results[i]`

<TypeTable
  type={{
    "title, company, location, department": { type: "string", description: "As the posting states them." },
    remote: { type: "boolean | null", description: "Whether the posting is marked remote." },
    salary: { type: "string | null", description: "The posting's own salary text." },
    "salary_min, currency": { type: "number, string | null", description: "Parsed from salary: \"$170K – $255.5K\" → 170000 USD." },
    posted_at: { type: "string | null", description: "The board's posting date." },
    url: { type: "string", description: "The posting on the company's board." },
    ats: { type: "string", description: "greenhouse, lever or ashby." },
  }}
/>

## Example

```json title="{ remote: true } · results[1] (trimmed)"
{
  "kind": "job",
  "title": "Security Engineer",
  "company": "patreon",
  "location": "Remote",
  "department": "Engineering",
  "remote": true,
  "salary": "$170K – $255.5K • Offers Equity • Multiple Ranges",
  "salary_min": 170000,
  "currency": "USD"
}
```

## Reading it

- `provenance.as_of` is when the index was last refreshed; it turns `stale` after 12 hours.
- Salary filters only match postings that state a salary; Greenhouse boards rarely do.
- "CA$215K" is Canadian dollars: filter with `currency` to compare like with like.
