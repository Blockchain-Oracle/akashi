---
title: What is the exchange rate?
description: POST /v1/fx returns each central bank's own fixing, its age, and whether the banks agree.
---

Rates come from the central banks themselves, through Frankfurter. When the quote currency's own central bank has a
current fixing, that is the headline rate; otherwise the median of the current fixings.

## Request

<TypeTable
  type={{
    base: { type: "string", description: "ISO 4217 code, e.g. USD.", required: true },
    quotes: { type: "string[]", description: "1 to 10 ISO 4217 codes.", required: true },
    amount: { type: "number", description: "An amount to convert; adds converted." },
    date: { type: "string (date)", description: "A historical date instead of the latest." },
  }}
/>

## Response: `results[i]`

<TypeTable
  type={{
    rate: { type: "number", description: "The headline rate." },
    date: { type: "string", description: "The newest fixing date." },
    converted: { type: "number | null", description: "amount × rate, when amount was given." },
    providers: { type: "ProviderRate[]", description: "Every bank asked: provider, rate, date, cadence (daily, weekly), issuer, freshness, business_days_old." },
    provenance: { type: "Provenance", description: "agreement and spread_pct across the current fixings." },
  }}
/>

## Example

```json title="{ base: USD, quotes: [EUR] } · results[0] (trimmed)"
{
  "kind": "fx_rate",
  "base": "USD",
  "quote": "EUR",
  "rate": 0.88067,
  "date": "2026-09-29",
  "providers": [
    { "provider": "FRED", "rate": 0.87719, "date": "2026-09-25", "cadence": "weekly", "freshness": "lagging" },
    { "provider": "BOE", "rate": 0.87986, "date": "2026-09-28", "cadence": "daily", "freshness": "lagging" },
    { "provider": "BOC", "rate": 0.88212, "date": "2026-09-29", "cadence": "daily", "freshness": "fresh" },
    { "provider": "ECB", "rate": 0.88067, "date": "2026-09-29", "cadence": "daily", "freshness": "fresh", "issuer": true }
  ],
  "provenance": {
    "sources": ["BOE", "BOC", "ECB"],
    "as_of": "2026-09-29",
    "freshness": "fresh",
    "agreement": "agree",
    "spread_pct": 0.2566,
    "licence": "central-bank reference data"
  }
}
```

## Reading it

- The ECB issues the euro, so its fixing is the headline.
- Fixings within one business day of the newest are compared; FRED's weekly series is listed but not compared.
- Within 0.5 % is `agree`, up to 1.5 % `minor_diff`, beyond that `conflict`.
- Disagreement is reported, not averaged away: USD→NGN on 2026-09-30 was `conflict` at 9.55 %, with every fixing listed.
