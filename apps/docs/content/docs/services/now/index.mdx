---
title: Live Facts
description: Facts a model cannot know from training, each with its sources, its age and whether they agree. Capability ID live-facts.
---

Every answer comes from the sources, not memory. Each result carries `provenance`: where the value came from, how old it
is against its source's own schedule, and whether independent sources agree.

<ServicePipeline service="now" />

## Endpoints

| Endpoint | Answers |
|---|---|
| [`/v1/time`](/docs/reference/now/time) · [`/v1/holidays`](/docs/reference/now/holidays) · [`/v1/business-days`](/docs/reference/now/business-days) | time zones, holidays, working days |
| [`/v1/fx`](/docs/reference/now/fx) | exchange rates from the issuing central banks |
| [`/v1/weather`](/docs/reference/now/weather) | the current forecast hour, two sources in the US |
| [`/v1/news`](/docs/reference/now/news) | recent headlines from GDELT and Hacker News |
| [`/v1/stocks`](/docs/reference/now/stocks) | US quotes, demo-grade |
| [`/v1/jobs`](/docs/reference/now/jobs) | postings from public company job boards |
| [`/v1/fact`](/docs/reference/now/fact) | current Wikidata statements |

Hard stop: 4 seconds. A source that misses it is named in `unavailable`; the rest of the answer still arrives.
