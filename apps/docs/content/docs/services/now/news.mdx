---
title: What is in the news?
description: POST /v1/news returns recent headlines from Akashi's GDELT index and live Hacker News, de-duplicated.
---

GDELT headlines come from Akashi's own index, refreshed every 15 minutes and kept for 72 hours. Hacker News is searched
live. The two lists alternate, and the same story from both is shown once.

## Request

<TypeTable
  type={{
    query: { type: "string", description: "Words that must all appear in the headline, 1 to 200 characters.", required: true },
    since_hours: { type: "integer", description: "1 to 72.", default: "24" },
    country: { type: "string", description: "ISO 3166-1 alpha-2: GDELT stories whose locations mention it." },
    limit: { type: "integer", description: "1 to 25.", default: "10" },
  }}
/>

## Response: `results[i]`

<TypeTable
  type={{
    title: { type: "string", description: "The headline." },
    url: { type: "string", description: "The story, with its domain." },
    seen_at: { type: "string", description: "When the source first saw it." },
    source: { type: "string", description: "gdelt or hn." },
    also_in: { type: "string[]", description: "The other source, when both carried it." },
    points: { type: "number | null", description: "The Hacker News score." },
    provenance: { type: "Provenance", description: "age_seconds from seen_at; the source's licence." },
  }}
/>

## Reading it

- `summary` counts stories per source.
- The same URL, or headlines at least 88 % alike, count as one story.
- Every word of the query must match; use a few distinctive words.
- A note appears when the GDELT index is more than 30 minutes old.
