---
title: What is true now?
description: POST /v1/fact returns the current value of a Wikidata property, with ended statements left out.
---

Office holders, capitals, populations and CEOs change. The answer keeps only current statements: not deprecated, no
end date in the past, preferred rank if marked, the latest point in time.

## Request

<TypeTable
  type={{
    subject: { type: "string", description: "A Wikidata ID (Q17) or a name (Japan), up to 200 characters.", required: true },
    property: { type: "string", description: "A property ID (P6), an alias (head of government, capital, population, ceo) or a label.", required: true },
  }}
/>

## Response: `results[0]`

<TypeTable
  type={{
    "subject_qid, subject_label": { type: "string", description: "What the subject resolved to." },
    "property_pid, property_label": { type: "string", description: "What the property resolved to." },
    values: { type: "FactValue[]", description: "The current statements: value, qid, unit, start, point_in_time, rank. Up to 10." },
    ended_values: { type: "number", description: "Statements left out because they have ended." },
    wikipedia_url: { type: "string | null", description: "The English Wikipedia article." },
    provenance: { type: "Provenance", description: "as_of is the item's last edit; licence CC0." },
  }}
/>

## Example

```json title="{ subject: \"Secretary-General of the United Nations\", property: \"officeholder\" } · results[0]"
{
  "kind": "fact",
  "subject_qid": "Q81066",
  "subject_label": "United Nations Secretary-General",
  "property_pid": "P1308",
  "property_label": "position holder",
  "values": [
    { "value": "António Guterres", "qid": "Q311440", "unit": null, "start": "2017-01-01", "point_in_time": null, "rank": "preferred" }
  ],
  "ended_values": 9,
  "wikipedia_url": "https://en.wikipedia.org/wiki/Secretary-General_of_the_United_Nations",
  "provenance": {
    "sources": ["wikidata"],
    "as_of": "2026-08-31T18:12:17Z",
    "freshness": "fresh",
    "agreement": "single_source",
    "licence": "CC0",
    "attribution": "Wikidata"
  }
}
```

## Reading it

- Check `subject_qid` and `property_pid` when you pass names.
- `ended_values: 9` are the earlier office holders, left out.
- `{"subject": "Japan", "property": "head of government"}` returned Sanae Takaichi, since 2025-10-21.
