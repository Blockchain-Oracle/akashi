---
title: Look up a current fact
description: Get the current value of a Wikidata property for any item (a head of government, a capital, a CEO, a population) with ended statements left out and the rules for "current" made explicit.
---

You will call `/v1/fact` with an item and a property and read which statement counts as current. You need a way to
call Akashi (the [mppx CLI](/docs/calling/curl-and-mppx) is the quickest; see [Calling Akashi](/docs/calling)).

## When to use it

- **Office holders and leadership** that change: presidents, prime ministers, secretaries-general, CEOs.
- **Figures that are revised**: population, GDP, number of employees.
- **Any Wikidata property** of any item, by its ID or by its label.

## Request

<TypeTable
  type={{
    subject: { type: "string", description: "A Wikidata item ID (Q17) or a name (Japan); up to 200 characters.", required: true },
    property: { type: "string", description: "A property ID (P6), a plain alias (head of government) or a property label.", required: true },
  }}
/>

Plain aliases include `head of state`, `president`, `head of government`, `prime minister`, `capital`, `population`,
`currency`, `ceo`, `headquarters`, `official website`, `founded`, `number of employees` and `time zone`. Anything else
is looked up as a property label on Wikidata.

## Send it

```json title="Request body"
{ "subject": "Secretary-General of the United Nations", "property": "officeholder" }
```

```bash title="Terminal"
MPPX_PRIVATE_KEY=0x... npx -y mppx@0.11.0 https://test.agent.pocket.network/v1/live-facts/v1/fact -J '{"subject":"Secretary-General of the United Nations","property":"officeholder"}' --protocol x402
```

  Akashi is registered on Pocket Network (Beta) but not yet listed on the agent portal, so this call works once
  `live-facts` is listed. The answer on this page is real, captured from the running service.

## Reading the answer

- **`subject_qid` and `property_pid`** show what the names resolved to: the item Q81066 and property P1308
  ("position holder"), found by searching Wikidata for "officeholder". Check them when you pass names.
- **`values`** holds the current statements, rendered as text: here António Guterres, holder since 2017-01-01
  (`start`).
- **`ended_values`: 9** counts the statements left out because they have an end date in the past, such as
  earlier holders of the office.
- **`rank: preferred`** means Wikidata's editors marked this statement as the preferred one.
- **`provenance.as_of`** is when the Wikidata item was last edited, and `age_seconds` how long ago.
- **`wikipedia_url`** links the English Wikipedia article for the item, when there is one.

## How "current" is decided

A property can hold many statements. The answer keeps, in order:

<Steps>
  <Step>Statements that are not deprecated and have a value.</Step>
  <Step>Of those, statements without an end time (P582) in the past.</Step>
  <Step>Of those, the preferred-rank statements, if any are marked preferred.</Step>
  <Step>If every remaining statement has a point in time (P585), only those with the latest date.</Step>
</Steps>

At most 10 values are returned. For example, `{"subject": "Japan", "property": "head of government"}` returned
Sanae Takaichi (since 2025-10-21) with 4 ended statements left out.

## Edge cases

<Accordions>
  <Accordion title="The name matches the wrong item">
    A name is looked up with Wikidata's search, preferring an exact label match. "New York" can be the city or the
    state; pass the item ID (Q60 for the city) when it matters.
  </Accordion>
  <Accordion title="An item has no English label">
    Labels fall back from English to Wikidata's multilingual default label, then to the English Wikipedia title, then to
    the ID itself.
  </Accordion>
  <Accordion title="Nothing matches">
    An unknown subject or property fails with `422 invalid_input`, naming what was not found.
  </Accordion>
  <Accordion title="Wikidata is not answering">
    The call fails with `422 invalid_input` ("Wikidata is not answering right now; retry shortly"), because there is no
    second source to answer from.
  </Accordion>
  <Accordion title="How fresh is a repeated call">
    An item is cached for 1 hour and labels for 7 days. `as_of` always shows the edit time of the item the answer used.
  </Accordion>
</Accordions>
