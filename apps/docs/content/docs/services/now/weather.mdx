---
title: What is the weather now?
description: POST /v1/weather returns the forecast for the current hour from MET Norway, cross-checked by the US weather service inside the US.
---

The values are the forecast for the current hour, not a station reading. Inside the US, NWS gives a second forecast
for the same hour and the two temperatures are compared.

## Request

<TypeTable
  type={{
    lat: { type: "number", description: "−90 to 90. Give lat and lon, or place." },
    lon: { type: "number", description: "−180 to 180." },
    place: { type: "string", description: "A place name, looked up on Wikidata, up to 100 characters." },
  }}
/>

## Response: `results[0]`

<TypeTable
  type={{
    valid_for: { type: "string", description: "The forecast hour." },
    temperature_c: { type: "number | null", description: "From MET Norway, with wind_speed_ms, wind_from_deg, humidity_pct, precipitation_next_hour_mm, conditions." },
    readings: { type: "SourceReading[]", description: "Each source's own forecast for the hour, converted to °C and m/s." },
    alerts: { type: "string[]", description: "Active NWS alert headlines for the point." },
    provenance: { type: "Provenance", description: "as_of is the forecast's issue time; agreement is on the temperature gap." },
  }}
/>

## Example

```json title="{ lat: 40.7128, lon: -74.006 } · results[0] (trimmed)"
{
  "kind": "weather",
  "valid_for": "2026-09-30T09:00:00Z",
  "temperature_c": 15.0,
  "wind_speed_ms": 1.8,
  "humidity_pct": 93.5,
  "conditions": "clearsky_night",
  "readings": [
    { "source": "met.no", "temperature_c": 15.0, "issued_at": "2026-09-30T08:19:59Z" },
    { "source": "nws", "temperature_c": 16.7, "conditions": "Partly Cloudy", "issued_at": "2026-09-30T06:37:45+00:00" }
  ],
  "alerts": [],
  "provenance": {
    "sources": ["met.no", "nws"],
    "as_of": "2026-09-30T08:19:59Z",
    "freshness": "fresh",
    "agreement": "minor_diff",
    "licence": "CC BY 4.0 (MET Norway)",
    "attribution": "Data from MET Norway"
  },
  "notes": ["values are the forecast for the current hour (nowcast), not a station observation", "temperature gap between sources: 1.7 °C"]
}
```

## Reading it

- Agreement is on the gap in degrees: up to 1.5 °C `agree`, up to 3.0 °C `minor_diff`.
- Outside the US only MET Norway answers, so `agreement` is `single_source`.
- Show "Data from MET Norway" wherever the values are displayed.
