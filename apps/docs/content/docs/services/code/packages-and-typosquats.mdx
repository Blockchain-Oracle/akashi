---
title: Is the package safe to install?
description: POST /v1/package and /v1/packages say whether a package exists, is a placeholder, or imitates a popular one.
---

Check a name before running `npm i` or `pip install`. `/v1/package` checks one, `/v1/packages` up to 100, and
`/v1/versions` lists versions and resolves a range.

## Request

<TypeTable
  type={{
    ecosystem: { description: "npm, pypi, cargo, go, maven, rubygems, packagist or nuget.", type: "string", required: true },
    name: { description: "The package name.", type: "string", required: true },
    version: { description: "A version to check. Without it, the latest.", type: "string" },
  }}
/>

`/v1/packages` takes `{ "items": [ { ecosystem, name, version? } ] }`, up to 100.

## Response: `results[i]`

<TypeTable
  type={{
    verdict: { description: "ok, does_not_exist, placeholder, likely_typo, suspicious_new, deprecated, yanked or unknown.", type: "string" },
    exists: { description: "yes, no or unknown.", type: "string" },
    typo_of: { description: "The popular package it is close to: name, distance, method, target_rank.", type: "TypoTarget | null" },
    did_you_mean: { description: "Real names to use instead.", type: "string[]" },
    evidence: { description: "What the verdict rests on, in words.", type: "string[]" },
    risk_signals: { description: "The same as codes: not_on_registry, typo_of_popular, placeholder, new_low_signal, version_not_found.", type: "string[]" },
    latest: { description: "The latest version, when it exists.", type: "string | null" },
    version_exists: { description: "Whether the version you asked for exists.", type: "string" },
    first_published: { description: "With latest_published, versions_count, downloads_last_week and popularity_rank.", type: "string | null" },
    deprecated: { description: "With deprecated_reason; yanked and yanked_reason likewise.", type: "boolean" },
  }}
/>

## Example

```json title="npm left-padx · results[0] (trimmed)"
{
  "kind": "package",
  "ecosystem": "npm",
  "name": "left-padx",
  "verdict": "does_not_exist",
  "exists": "no",
  "risk_signals": ["not_on_registry"],
  "typo_of": { "name": "left-pad", "distance": 1, "method": "damerau_levenshtein", "target_rank": 5550 },
  "did_you_mean": ["left-pad"],
  "evidence": ["'left-padx' is not published on npm", "closest popular name: 'left-pad' (distance 1)"],
  "retryable": false
}
```

## Reading it

- `placeholder`: registered to hold nothing (`react-codeshift`: "🚫 Placeholder to prevent dependency confusion.").
- `likely_typo`: within two edits of a package at least 100× more popular.
- `suspicious_new`: first published under 90 days ago, with almost no downloads.
- Known vulnerabilities are out of scope; `see_also` points to Pocket's `package-advisories` and `taint-check`.
