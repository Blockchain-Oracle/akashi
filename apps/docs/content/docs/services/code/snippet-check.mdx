---
title: Does the code call real things?
description: POST /v1/check returns one diagnostic, with its position, for every import and call in a snippet.
---

The snippet is parsed and each reference is checked against the real registry and the version you pin. Standard
libraries are skipped. At most 60 references are checked per snippet.

## Request

<TypeTable
  type={{
    language: { description: "python, typescript, javascript, go or rust.", type: "string", required: true },
    code: { description: "The snippet, up to 49,152 characters.", type: "string", required: true },
    versions: { description: "Pinned versions, package → version, up to 50. Unpinned packages are checked at their latest.", type: "Record<string, string>", default: "{}" },
  }}
/>

## Response: `results[i]`, one per reference

<TypeTable
  type={{
    verdict: { description: "ok, nonexistent_package, placeholder, likely_typo, suspicious_new, nonexistent_symbol, deprecated or unknown.", type: "string" },
    line: { description: "Line (from 1), with column, end_line and end_column (columns from 0).", type: "number" },
    text: { description: "What was checked, e.g. axios.fetchJson.", type: "string" },
    ref_kind: { description: "import, call or attribute.", type: "string" },
    package: { description: "The package it belongs to.", type: "string | null" },
    version: { description: "The version checked.", type: "string | null" },
    target: { description: "The symbol looked up.", type: "string | null" },
    fix_hint: { description: "The likely fix, e.g. \"did you mean 'requests'?\".", type: "string | null" },
    did_you_mean: { description: "Close real names.", type: "string[]" },
    signature: { description: "The real signature, when the symbol exists.", type: "string | null" },
    reason: { description: "The evidence behind a package verdict.", type: "string | null" },
  }}
/>

## Example

```python title="snippet"
import reqeusts

r = reqeusts.get("https://example.com")
```

```json title="results[0] (trimmed)"
{
  "kind": "diagnostic",
  "line": 1,
  "column": 0,
  "text": "reqeusts",
  "ref_kind": "import",
  "package": "reqeusts",
  "verdict": "nonexistent_package",
  "fix_hint": "did you mean 'requests'?",
  "did_you_mean": ["requests", "grequests"],
  "reason": "'reqeusts' is not published on pypi; closest popular name: 'requests' (distance 1)"
}
```

## Reading it

- A missing package marks every line that uses it: it is the root cause.
- Symbols are only looked up in packages that exist (`axios.fetchJson` → `nonexistent_symbol`).
- `unknown` means "could not check in time", never "does not exist".
- Pin `versions` to check what you will actually install.
