---
title: Check that a function exists
description: Ask /v1/symbol whether a function, class or method exists in a package version, and get its real signature.
---

You will check a single symbol, such as `pandas.DataFrame.to_markdown`, against the published package and read its
signature. You need a way to call Akashi (see [Call Akashi](/docs/calling)).

## When to use it

When generated code calls a method you have not seen, or when you want the real signature before writing a call.
`/v1/symbol` checks one symbol and `/v1/symbols` up to 50 in the same package.

## Where the answer comes from

The symbol is looked up in the package as published, never in a model's memory:

| Ecosystem | Source | `evidence_source` |
|---|---|---|
| npm | The package's TypeScript declarations, read with the TypeScript compiler | `d.ts` |
| PyPI | Stubs and source read from the wheel (standard library from typeshed) | `pyi`, `py-ast`, `typeshed` |
| crates.io | rustdoc JSON from docs.rs | `rustdoc` |
| Go | pkg.go.dev | `pkgsite` |

Other ecosystems answer `exists: "unknown"` with the reason `symbols_not_supported_for_ecosystem`.

## Request

<TypeTable
  type={{
    ecosystem: { description: "One of npm, pypi, cargo or go for symbol lookups.", type: "string", required: true },
    package: { description: "The package name (for npm, a subpath such as next/server also works).", type: "string", required: true },
    version: { description: "The version to check. Without it the latest is used.", type: "string" },
    symbol: { description: "A dotted path such as DataFrame.to_markdown (Rust uses ::), up to 300 characters. /v1/symbols takes symbols: string[] instead, up to 50.", type: "string", required: true },
  }}
/>

## Send it

```bash title="Does pandas have DataFrame.to_markdown?"
MPPX_PRIVATE_KEY=0x... npx -y mppx@0.11.0 https://test.agent.pocket.network/v1/code-reality-check/v1/symbol -J '{"ecosystem": "pypi", "package": "pandas", "symbol": "DataFrame.to_markdown"}' --protocol x402
```

<Callout type="warn" title="Not on the portal yet">
  Akashi's services are registered on Pocket Network (Beta) but not yet listed on the agent portal, so this call works
  once they are listed. The answers on this page were captured from the running service.
</Callout>

The command pays with a Base Sepolia wallet through x402. To set up a client in code, see [Call Akashi](/docs/calling).

## Reading the answer

- **`exists`** is `yes`, `no` or `unknown`, and **`package_exists`** says whether the package itself was found.
- **`resolved_version`** is the version that was read (the latest, when you gave none).
- **`symbol_kind`** is `function`, `class`, `method`, `attribute`, `type`, `module` and similar.
- **`signature`** is the declared signature, and **`overloads`** lists every overload when there are several.
- **`defined_in`** is where the symbol is actually defined, which may differ from where it is re-exported.
- **`did_you_mean`** lists close real names when the symbol does not exist.
- **`pending`** and **`retry_after_ms`**: see the edge cases below.

## Edge cases

<Accordions type="single">
  <Accordion title="pending: true">
    For an npm package that has not been read before, building its type information can take longer than five
    seconds. The answer is then `exists: "unknown"` with `pending: true` and `retry_after_ms: 3000`; the build
    finishes in the background, and asking again after that delay gives the real answer.
  </Accordion>
  <Accordion title="The package or version does not exist">
    `exists` is `no`, `package_exists` is `no`, and `reason` is `package_or_version_not_found`. Check the package
    with [`/v1/package`](/docs/services/code/packages-and-typosquats) to see why.
  </Accordion>
  <Accordion title="The registry did not answer">
    `exists` is `unknown` with the reason `registry_unavailable`, and the source is named in the envelope's
    `unavailable` list.
  </Accordion>
  <Accordion title="Pin a version for a stable answer">
    Answers for a pinned version are cached permanently, because a published version never changes. Without a
    version, the latest is resolved each time.
  </Accordion>
</Accordions>
