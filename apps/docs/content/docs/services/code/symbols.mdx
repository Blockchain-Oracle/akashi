---
title: Does the function exist?
description: POST /v1/symbol and /v1/symbols check a function, class or method in a package version and return its real signature.
---

Symbols are read from the package's published type information: `.pyi` stubs or source for Python, `.d.ts` for npm,
rustdoc JSON for Rust, and pkg.go.dev for Go.

## Request

<TypeTable
  type={{
    ecosystem: { description: "npm, pypi, cargo or go.", type: "string", required: true },
    package: { description: "The package (npm subpaths such as next/server work).", type: "string", required: true },
    version: { description: "The version. Without it, the latest.", type: "string" },
    symbol: { description: "A dotted path such as DataFrame.to_markdown (Rust uses ::). /v1/symbols takes symbols: string[], up to 50.", type: "string", required: true },
  }}
/>

## Response: `results[i]`

<TypeTable
  type={{
    exists: { description: "yes, no or unknown.", type: "string" },
    package_exists: { description: "Whether the package itself exists.", type: "string" },
    resolved_version: { description: "The version checked.", type: "string | null" },
    symbol_kind: { description: "function, class, method, attribute, type or module.", type: "string | null" },
    signature: { description: "The real signature.", type: "string | null" },
    overloads: { description: "Every overload, when there are several.", type: "string[]" },
    defined_in: { description: "Where it is defined.", type: "string | null" },
    did_you_mean: { description: "Close real names, when it does not exist.", type: "string[]" },
    evidence_source: { description: "pyi, py-ast, d.ts, rustdoc, pkgsite or typeshed.", type: "string | null" },
    pending: { description: "true while type information is still loading; retry after retry_after_ms.", type: "boolean" },
  }}
/>

## Example

```json title="pypi pandas DataFrame.to_markdown · results[0] (trimmed)"
{
  "kind": "symbol",
  "ecosystem": "pypi",
  "package": "pandas",
  "symbol": "DataFrame.to_markdown",
  "package_exists": "yes",
  "resolved_version": "3.0.6",
  "exists": "yes",
  "symbol_kind": "method",
  "signature": "def to_markdown(self, buf: None=..., *, mode: str=..., index: bool=..., storage_options: StorageOptions | None=..., **kwargs) -> str",
  "defined_in": "pandas.core.frame.DataFrame.to_markdown",
  "evidence_source": "py-ast",
  "pending": false
}
```

## Reading it

- `exists: no` with `package_exists: yes` means the package is real but the symbol is not.
- `pending: true` is not an answer yet: ask again after `retry_after_ms`.
- The signature is quoted from the published types, so it can be shown to a user as-is.
