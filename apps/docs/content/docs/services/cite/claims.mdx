---
title: Does the source say it?
description: POST /v1/claim checks a claim against the cited source's abstract, or text you send, and returns the sentence that decides it.
---

A citation can be real and still not say what it is cited for. Akashi verifies the source, reads its abstract and
scores the closest sentences with a natural-language-inference model.

## Request

<TypeTable
  type={{
    claim: { description: "The claim, up to 1,000 characters.", type: "string", required: true },
    citation: { description: "The source it is attributed to. Give this, evidence_text, or both.", type: "string | StructuredCitation" },
    evidence_text: { description: "The source text, up to 20,000 characters. Used instead of fetching an abstract.", type: "string" },
  }}
/>

## Response: `results[i]`

<TypeTable
  type={{
    verdict: { description: "supported, contradicted, insufficient_evidence or unverifiable.", type: "string" },
    evidence_sentence: { description: "The sentence (or pair) that decided it. Quote this.", type: "string | null" },
    scores: { description: "That sentence's entailment, neutral and contradiction probabilities.", type: "{ entailment, neutral, contradiction }" },
    evidence_scope: { description: "abstract or provided_text.", type: "string | null" },
    premise_source: { description: "Where the text came from: europepmc, openalex, datacite or provided_text.", type: "string | null" },
    model: { description: "The inference model that scored it.", type: "string | null" },
    citation: { description: "The source's own verification, as /v1/verify returns it.", type: "CitationResult | null" },
    reasons: { description: "Why, e.g. \"the cited work is retracted\".", type: "string[]" },
    retryable: { description: "Whether asking again could change the answer.", type: "boolean" },
  }}
/>

## Example

```json title="\"Transformers rely entirely on recurrence\" · arXiv:1706.03762 · results[0] (trimmed)"
{
  "kind": "claim",
  "verdict": "contradicted",
  "scores": { "entailment": 0.0005, "neutral": 0.0005, "contradiction": 0.999 },
  "evidence_sentence": "We propose a new simple network architecture, the Transformer, based solely on attention mechanisms, dispensing with recurrence and convolutions entirely. Experiments on two machine translation tasks show these models to be superior in quality while being more parallelizable and requiring significantly less time to train.",
  "evidence_scope": "abstract",
  "premise_source": "datacite",
  "model": "deberta-v3-base-mnli-fever-anli",
  "reasons": [],
  "retryable": false
}
```

## Reading it

- `supported` needs entailment ≥ 0.80 and contradiction < 0.20; `contradicted` needs contradiction ≥ 0.80.
- Only a sentence sharing a content word with the claim can decide the verdict.
- A retracted source is flagged in `reasons`, whatever the verdict.

<Accordions type="single">
  <Accordion title="The first claim after a quiet spell is unverifiable">
    The model loads on demand and unloads after 15 idle minutes. A claim sent while it loads is `unverifiable`
    with `retryable: true`. Ask again a few seconds later.
  </Accordion>
  <Accordion title="No abstract to read">
    If the source is not verified, has no DOI, or no source holds its abstract, the answer is
    `insufficient_evidence`. Send the text as `evidence_text`.
  </Accordion>
</Accordions>
