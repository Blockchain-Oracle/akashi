title: Citation Verifier
description: Is the citation real, does it match its record, and does the source say what it is cited for? Capability ID citation-verify.
---

Each citation is looked up where it is defined and answered with a verdict, the matched record and the fields that
disagree. A retraction overrides every other verdict.

## Endpoints

| Endpoint | Answers |
|---|---|
| [`POST /v1/verify`](/docs/reference/cite/verify) | up to 10 citations: does each exist and match? |
| [`POST /v1/claim`](/docs/reference/cite/claim) | does the source support the claim attributed to it? |

`not_found` is given only after a complete search. If a source was missing, the answer is `unverifiable` with
`retryable: true`.
