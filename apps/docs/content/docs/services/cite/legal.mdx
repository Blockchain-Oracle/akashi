---
title: Check a court case citation
description: Find out whether a US case citation points at a real case, the right case, or the middle of someone else's.
---

You will check a case citation such as `347 U.S. 483` and learn what each answer means. Case citations use the
same endpoint as every other citation, [`POST /v1/verify`](/docs/reference/cite/verify).

## When to use it

Whenever a model cites US case law: a brief, a memo, a summary of precedent. In *Mata v. Avianca* (S.D.N.Y. 2023)
lawyers filed a brief whose cases a chatbot had invented; this check catches that kind of citation.

## How a case citation is checked

A fabricated case citation usually points at a real reporter volume, so the check is structural. Akashi reads the
reporter, volume and page (and the party names and year when present), then looks at every case in that volume of
the Caselaw Access Project:

- **A case starts on that page.** The party names and year are compared with it: `verified` if they match,
  `mismatch` with `field_diffs` if not.
- **The page is inside the case you named.** You gave a pin cite rather than the first page: `mismatch` with a
  `minor` page difference.
- **The page is inside a different case.** No case can start there: `not_found`, reason `page_inside_other_case`.
- **Nothing is on that page.** `not_found`, reason `no_case_at_page`.

## Request

Send the citation as written, or as a structured object with `legal_cite`.

<TypeTable
  type={{
    citations: {
      description: "Case citations such as \"Brown v. Board of Education, 347 U.S. 483 (1954)\", 1 to 10 per request.",
      type: "(string | { legal_cite: string })[]",
      required: true,
    },
  }}
/>

Coverage is the Caselaw Access Project (CC0). The last year each reporter covers:

| Reporter | Covered through |
|---|---|
| U.S. | 2014 |
| S. Ct. | 2020 |
| F.3d | 2019 |
| F.2d | 1993 |
| F. | 1932 |
| F. Supp. | 1998 |
| F. Supp. 2d | 2014 |
| F. Supp. 3d | 2019 |

## Send it

```bash title="Check the Varghese citation from Mata v. Avianca"
MPPX_PRIVATE_KEY=0x... npx -y mppx@0.11.0 https://test.agent.pocket.network/v1/citation-verify/v1/verify -J '{"citations": ["Varghese v. China Southern Airlines Co., 925 F.3d 1339 (11th Cir. 2019)"]}' --protocol x402
```

<Callout type="warn" title="Not on the portal yet">
  Akashi's services are registered on Pocket Network (Beta) but not yet listed on the agent portal, so this call works
  once they are listed. The answers on this page were captured from the running service.
</Callout>

The command pays with a Base Sepolia wallet through x402. To set up a client in code, see [Call Akashi](/docs/calling).

## Reading the answer

- **`verdict`** is `not_found` and **`reasons`** says why in two forms: a code (`page_inside_other_case`) and a
  sentence naming the case that occupies those pages, *J.D. v. Azar* (925 F.3d 1291–1349).
- **`legal`** echoes what was read from your citation (`reporter`, `volume`, `page`) and, when a case was matched,
  its `case_name`, `date_filed` and `court`. `covered_through` is the last year the reporter is covered.
- **`legal.link`** opens the same citation on CourtListener, so a person can check it.
- **`confidence`** is 0.95 for every structural answer from the case index.
- **`retryable: false`**: asking again gives the same answer.

## Edge cases

<Accordions type="single">
  <Accordion title="Several cases in one string">
    Only the first full case citation in a string is checked. Send each case as its own item in `citations`.
  </Accordion>
  <Accordion title="A reporter that is not covered">
    A reporter outside the list above, or a citation dated after its coverage, comes back `unverifiable` with
    `retryable: false` and a reason naming the limit.
  </Accordion>
  <Accordion title="The volume is not in the index">
    If the Caselaw Access Project has no such volume, the answer is `unverifiable` ("is not indexed"), not
    `not_found`.
  </Accordion>
  <Accordion title="The case index did not answer">
    The answer is `unverifiable` with `retryable: true`, and `case.law` appears in the envelope's `unavailable` list.
  </Accordion>
  <Accordion title="Statutes">
    Statute citations are recognised and answered `unverifiable`, with a pointer to Pocket's `us-code-cfr` service.
  </Accordion>
</Accordions>
