---
title: Is the court case real?
description: A US case citation is checked by reporter, volume and page against the Caselaw Access Project.
---

Invented case citations usually point at a real volume, so the check is structural: does a case start on that page?
Case citations use the same endpoint, [`POST /v1/verify`](/docs/reference/cite/verify).

## Request

<TypeTable
  type={{
    citations: {
      description: "Case citations as written, such as \"Brown v. Board of Education, 347 U.S. 483 (1954)\", or { legal_cite }. 1 to 10.",
      type: "(string | { legal_cite: string })[]",
      required: true,
    },
  }}
/>

## Response: `results[i].legal`

<TypeTable
  type={{
    reporter: { description: "The reporter read from the citation, e.g. F.3d.", type: "string" },
    volume: { description: "The volume.", type: "string" },
    page: { description: "The page.", type: "string" },
    case_name: { description: "The case that starts on that page, when one does.", type: "string | null" },
    date_filed: { description: "Its decision date.", type: "string | null" },
    court: { description: "Its court.", type: "string | null" },
    link: { description: "The same citation on CourtListener.", type: "string" },
    covered_through: { description: "The last year this reporter is covered.", type: "number" },
  }}
/>

| What is on that page | Verdict |
|---|---|
| the case you named | `verified` (or `mismatch` if the name or year differs) |
| inside the case you named (a pin cite) | `mismatch`, minor page difference |
| inside a different case | `not_found`, reason `page_inside_other_case` |
| nothing | `not_found`, reason `no_case_at_page` |
| beyond coverage | `unverifiable` |

Coverage ends: U.S. 2014 · S. Ct. 2020 · F.3d 2019 · F.2d 1993 · F. Supp. 2d 2014 · F. Supp. 3d 2019.

## Example

The case invented for the brief in *Mata v. Avianca* (S.D.N.Y. 2023).

```json title="Varghese v. China Southern Airlines Co., 925 F.3d 1339 (11th Cir. 2019) · results[0]"
{
  "kind": "citation",
  "input_kind": "legal",
  "verdict": "not_found",
  "confidence": 0.95,
  "legal": {
    "reporter": "F.3d",
    "volume": "925",
    "page": "1339",
    "case_name": null,
    "link": "https://www.courtlistener.com/c/F.3d/925/1339/",
    "covered_through": 2019
  },
  "reasons": [
    "page_inside_other_case",
    "page 1339 falls inside J.D. v. Azar (925 F.3d 1291-1349); no case starts there"
  ],
  "retryable": false
}
```

## Reading it

- `reasons` names the case that occupies those pages.
- `legal.link` lets a person check it on CourtListener.
- `retryable: false`: the answer will not change.

<Accordions type="single">
  <Accordion title="Several cases in one string">Only the first is checked. Send each as its own item.</Accordion>
  <Accordion title="The case index did not answer">The verdict is `unverifiable` with `retryable: true`, and `case.law` is in `unavailable`.</Accordion>
