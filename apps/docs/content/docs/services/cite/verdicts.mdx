---
title: Does the citation exist and match?
description: POST /v1/verify checks up to 10 citations and returns one verdict per citation, with the record it matched.
---

Send DOIs, arXiv IDs, PubMed IDs, reference lines or URLs. Each comes back with a verdict and the evidence behind it.
To call it from an agent, see [From an agent](/docs/pocket/from-an-agent).

## Request

<TypeTable
  type={{
    citations: {
      description: "1 to 10 citations. Each is a string (up to 2,000 characters) or a structured citation with doi, arxiv, pmid, title, authors, year, venue, volume, pages, url, legal_cite or raw.",
      type: "(string | StructuredCitation)[]",
      required: true,
    },
    "options.check_urls": { description: "Fetch cited URLs. When false, URL citations are unverifiable.", type: "boolean", default: "true" },
    "options.retraction": { description: "Look up retractions and corrections.", type: "boolean", default: "true" },
  }}
/>

## Response: `results[i]`

<TypeTable
  type={{
    verdict: { description: "verified, mismatch, not_found, retracted, ambiguous or unverifiable.", type: "string" },
    input_kind: { description: "How the input was read: scholarly, legal, web or statute.", type: "string" },
    confidence: { description: "0.99 for an identifier that resolves and agrees; otherwise the match score.", type: "number" },
    matched: { description: "The record it was checked against: doi, title, authors, year, venue, volume, pages, url, record_source.", type: "MatchedRecord | null" },
    field_diffs: { description: "Each field that disagrees: given, found, severity (major or minor).", type: "FieldDiff[]" },
    retraction: { description: "status (retracted, corrected, expression_of_concern, none), date, notice_doi, source.", type: "Retraction | null" },
    candidates: { description: "Up to three records, only when the verdict is ambiguous.", type: "MatchedRecord[]" },
    web: { description: "For URLs: http_status, liveness (live, dead, blocked, unreachable), page_title, archived_url.", type: "WebCheck | null" },
    reasons: { description: "Why, for any verdict that is not self-evident.", type: "string[]" },
    retryable: { description: "Whether asking again could change the answer.", type: "boolean" },
  }}
/>

## Example

A real paper cited with the wrong year.

```json title="{ doi: 10.1038/nature14539, year: 2016 } · results[0] (trimmed)"
{
  "kind": "citation",
  "input_kind": "scholarly",
  "verdict": "mismatch",
  "confidence": 0.955,
  "matched": {
    "doi": "10.1038/nature14539",
    "title": "Deep learning",
    "authors": ["LeCun", "Bengio", "Hinton"],
    "year": 2015,
    "venue": "Nature",
    "record_source": "crossref"
  },
  "field_diffs": [{ "field": "year", "given": "2016", "found": "2015", "severity": "minor" }],
  "retraction": { "status": "none", "date": null, "notice_doi": null, "source": null },
  "candidates": [],
  "reasons": [],
  "retryable": false
}
```

## Reading it

- `mismatch`: the work exists; `field_diffs` shows what to correct.
- Any year difference blocks `verified`, even a `minor` one.
- `matched.record_source` names the registry the record came from.
- A retracted work comes back `retracted` with its date and notice DOI (Wakefield 1998 → 2010-02-06).

<Accordions type="single">
  <Accordion title="Free text came back unverifiable">
    Free text is `not_found` only after Crossref and OpenAlex both answered. Otherwise it is `unverifiable` with
    `retryable: true`. Send the DOI, or ask again.
  </Accordion>
  <Accordion title="URL citations">
    A dead link with an archived copy is `verified` at lower confidence. A site that refuses automated access
    (401, 403, 429) is `unverifiable`, never dead.
  </Accordion>
  <Accordion title="Statutes">
    Statutes such as 42 U.S.C. § 1983 are `unverifiable`; Pocket's `us-code-cfr` service covers them.
  </Accordion>
</Accordions>
